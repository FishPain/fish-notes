# Design docs

Working design notes and build plans for Fish Notes. These are a historical record of
how the app was designed and built — useful for understanding *why* things are the way
they are, not step-by-step contributor docs (see the root [README](../README.md) and
[CONTRIBUTING](../CONTRIBUTING.md) for that).

- [`specs/`](./specs) — feature/design specs.
- [`plans/`](./plans) — dated implementation plans by phase.
